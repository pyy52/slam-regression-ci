# Examples

Deterministic synthetic data so you can try the tool in under a minute.
All files are generated by [`scripts/gen_examples.py`](../scripts/gen_examples.py)
(fixed seeds; regenerating produces identical trajectories).

| File | Meaning |
|---|---|
| `reference.tum` | Ground-truth trajectory (one full circle, 200 poses, TUM format) |
| `baseline.tum` | Estimate with small Gaussian noise — the "good" version |
| `candidate_degraded.tum` | Estimate with larger noise and linear drift — the "regressed" version |
| `baseline_metrics.json` | Baseline metrics recorded for `baseline.tum` (commit such files in your repo) |
| `regression.yaml` | Threshold configuration used in the examples |

Try it from the repository root:

```bash
pip install .
# 1) This passes (baseline compared against itself, ~0% change):
slam-regression compare \
  --baseline examples/baseline_metrics.json \
  --reference examples/reference.tum \
  --estimate examples/baseline.tum \
  --config examples/regression.yaml

# 2) This fails with exit code 1 (noise + drift clearly regress ATE/RPE):
slam-regression compare \
  --baseline examples/baseline_metrics.json \
  --reference examples/reference.tum \
  --estimate examples/candidate_degraded.tum \
  --config examples/regression.yaml \
  --report report.md --json report.json
echo $?
```
