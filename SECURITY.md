# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | yes       |

## Reporting a vulnerability

This is a small offline developer tool: it parses trajectory files and prints
reports. It does not open network connections, execute trajectory file
contents, or run any external code.

If you believe you have found a security issue (for example, a parser
vulnerability that could be triggered by a malicious trajectory file), please
report it privately:

1. Open a
   [private security advisory](https://github.com/pyy52/slam-regression-ci/security/advisories/new)
   on this repository, **or**
2. Contact the maintainer via GitHub (`pyy52`).

Please do not open a public issue for an unpatched vulnerability. Reports will
be acknowledged as quickly as possible and credited if desired.
